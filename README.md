# Georgia Boat Rental Landing Page

This repository is for building the waitlist landing page for the Georgia boat rental launch.

The landing page exists to validate demand before the broader product rollout. Its job is to explain the launch clearly, make the brand feel credible, and capture qualified interest from people who want to rent boats on the first supported Georgia lakes.

## Purpose

The landing page should do four things well:

- explain the value proposition quickly
- present the initial Georgia launch story in a way that is easy to trust
- collect waitlist leads with enough detail to qualify interest
- record which lake each prospective renter cares about so launch demand can be prioritized

This repo is intentionally focused on that landing page outcome. It is not the codebase for the renter mobile app or for internal operations tooling.

## Core Product Goals

The landing page should help the team answer a simple question: where is real demand strongest, and who is ready to book when supply goes live?

To support that goal, the site should:

- capture contact information for waitlist signups
- collect lake preference for launch planning
- communicate trust signals for a new rental brand
- support analytics around traffic and conversion
- give the team a clean foundation for testing and production deployment

## Launch Market Context

The current launch plan is centered on five Georgia lake markets:

1. Lake Sidney Lanier
2. Hartwell Lake
3. Allatoona Lake
4. J. Strom Thurmond Lake
5. Walter F. George Lake

When prioritization is needed, the default emphasis is Lake Sidney Lanier and Allatoona Lake.

## Scope

In scope for this repository:

- landing page UX and content
- waitlist capture flows
- lake-interest collection
- analytics and conversion measurement
- testing and deployment work for the landing page

Out of scope for this repository:

- renter mobile app implementation
- marketplace or fleet operations systems
- back-office automation beyond what the landing page needs
- broader marketing execution outside the site itself

## Current State

The repository is currently greenfield and holds planning artifacts for the work. As implementation begins, this repo should become the dedicated home for the landing page build, test, and deployment workflow.
